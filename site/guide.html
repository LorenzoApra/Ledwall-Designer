01 / Installation

Choose your installer from the download section. Get packages from this project’s GitHub Releases. The “Source code” archives are for building the app yourself.

macOS · Apple Silicon or Intel

  1. Open Apple menu → About This Mac. If you see an Apple M-series chip, choose Apple Silicon. If you see an Intel processor, choose Intel. Both packages target macOS 12 or later.
  2. Open the downloaded .dmg and drag Ledwall Designer to Applications.
  3. Eject the disk image and launch the app from Applications.
  4. If macOS blocks it, attempt to open the app once, then open System Settings → Privacy & Security → Open Anyway and confirm. On macOS 12, this is in System Preferences → Security & Privacy → General.

The app is ad-hoc signed but is not Developer ID signed or notarized by Apple. Approve only the copy you downloaded from this repository. See Apple’s guidance for opening apps.

Windows · Intel/AMD 64-bit

  1. On Windows 10/11 x64, download and run Ledwall-Designer-1.0.0-windows-x64-setup.exe.
  2. The installer is unsigned. If SmartScreen appears, verify the official download source, then use More info → Run anyway if that option is available.
  3. Follow the installer and launch Ledwall Designer. The app installs for the current user.

WebView2 is required. If it is missing, setup downloads it; an Internet connection may therefore be needed for first installation. The installed app can work offline. If your organization blocks unsigned software, ask your administrator.

02 / Your first project

  1. Progetto — Enter your project/event name and revision. Set the master canvas size in pixels. Names and revisions appear in your exported files.
  2. Librerie — Check your equipment: cabinet resolution, dimensions, power and weight, plus the selected controller.
  3. Disegno → Crea bulk — Create a grid of cabinets. Use + Schermo to add screens and Canvas X / Canvas Y to place them on the master canvas.
  4. Arrange cabinets on the canvas, use Snap for alignment and scroll to zoom around the pointer.
  5. Continue through Dati, Elettrico and Peso, then save and export.

Cmd/Ctrl-click adds or removes a cabinet from the selection; Shift-click selects a row. You can delete selected cabinets together, assign them to a data port or power line, or exclude them from the pixel map while keeping them in structural and weight calculations.

03 / Equipment libraries

Librerie groups equipment into Cabinet, Sending Card and Accessori. Entries are editable and saved locally on your computer. An initial equipment library ships with the app.

CSV import and updates

Use a local semicolon-separated CSV for shared library data. Preserve the structure of the bundled CSV. Aggiorna dalla rete fetches and validates the official public library; a failed update keeps the existing library.

New equipment IDs included with the app are added without overwriting existing local IDs. Keep a copy of the CSV you use for custom equipment.

NovaStar configuration files

Import .rcfg, .rcfgx or .rfcg to read cabinet resolution, module pixel dimensions, scan and receiving-card data where available. Verify physical dimensions, pitch, weight and power separately.

Projects reference library model IDs. When sharing a .lwd project, make sure the other computer has the same custom library. The project does not embed the full equipment library.

04 / Data & power

Data ports · Dati

Choose the controller and review frame rate, bit depth, HDR, 3D, low latency, redundancy and safety margin where applicable. Create automatic wiring and inspect the capacity warnings, or draw each route manually.

  1. Select the first cabinet and choose a port, or click + Nuova porta (N).
  2. Press and drag through cabinets in their physical cable order.
  3. Finish with Enter, Escape, a double-click on the canvas or Termina.
  4. Use Annulla ultimo tratto to undo the last segment or Rimuovi cabinet dalla porta to disconnect a cabinet.

Under Porte e backup, assign free backup ports automatically or set internal backup and spare-controller references manually.

MCTRL/VX: port load uses the bounding pixel rectangle, so empty areas in irregular shapes count as virtual pixels. COEX/MX: port load uses actual pixel totals. Review both real and virtual pixel values when a port appears overloaded.

Power lines · Elettrico

Set voltage, breaker rating and utilization. Assign lines automatically, or select a cabinet and choose + Nuova linea (N). Drag through the cabinets and finish the route as above. Each line reports cabinet count and maximum/average power in W or kW.

05 / Weight & rigging

In Peso, configure cable/accessory weights and suspension points. Add flybars to selected columns for hanging or ground support. Review supported load, capacity and utilization for each flybar.

Add support plates manually or generate them at internal 2×2 cabinet joints using the configured height threshold. Simple plates and plates with truss clamps are available. Drag flybars and plates to position them on the layout.

The initial MG7S beam capacity is 200 kg; its own weight is zero until you enter a verified value. Review these inputs against the actual equipment. Rigging outputs are planning estimates, not structural certification.

06 / Save & export

Salva saves a local .lwd project. Use Salva con nome for another location and Apri to reopen it. Saving is manual; the desktop app asks you to save, discard or cancel when closing with unsaved changes.

In Pixelmap, configure grid, coordinate, test-pattern, name, resolution and logo overlays. In Output, create the deliverables below.

08 / Troubleshooting

macOS or Windows blocks the app

Follow the per-app approval steps in Installation. Packages have no publisher certificate. Verify the official download source and the processor variant; on a managed device, your administrator may need to approve installation.

Why does Windows setup need Internet?

The installer downloads Microsoft WebView2 if it is not already installed. Normal design, calculation and export work is local after installation.

A data port is overloaded even though the pixel total looks small

Check controller mode settings and the bounding rectangle on MCTRL/VX. Empty space inside the rectangle contributes virtual pixels. Splitting the route across ports can reduce the required load.

The network library update fails

Your current local library stays available. Continue offline, import a local CSV, or retry the network update later.

My project looks different on another computer

Check that both installations have the same custom equipment library. Project files reference model IDs and do not embed the full library.

How do I report a problem?

Open a GitHub issue with version, operating system, processor, reproduction steps and a minimal project if possible. Remove private event and client information before sharing files.
