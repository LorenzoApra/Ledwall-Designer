# Ledwall Designer V1.0

First public release of the offline desktop tool for LED wall layout, data/power
cabling, pixel maps and technical documentation.

## Downloads

| Computer | File |
| --- | --- |
| Mac Apple Silicon (M-series), macOS 12+ | `Ledwall-Designer-1.0.0-macos-arm64.dmg` |
| Mac Intel, macOS 12+ | `Ledwall-Designer-1.0.0-macos-x64.dmg` |
| Windows 10/11, Intel/AMD x64 | `Ledwall-Designer-1.0.0-windows-x64-setup.exe` |

Download an installer from **Assets** below. GitHub's “Source code” archives are
for developers. `SHA256SUMS.txt` contains the checksums of all three installers.

## Included

- Multi-screen cabinet layouts and master canvas positioning.
- NovaStar controller capacity checks, manual/automatic data wiring and backup ports.
- Power-line planning, flybars, support plates and estimated rigging loads.
- PNG pixel maps, technical reports/bills of materials and A3 wiring PDFs.
- Local `.lwd` projects, CSV equipment libraries and RCFG/RCFGX import.

## Installation and current limitations

**macOS:** open the DMG and drag the app to Applications. The app is ad-hoc signed
but not Developer ID signed or notarized. After a blocked first launch, use
System Settings → Privacy & Security → Open Anyway (Security & Privacy on macOS 12).

**Windows:** run the setup executable. The installer is unsigned, so Windows may
show a publisher warning. WebView2 is downloaded during setup if it is missing.

The application interface is currently **Italian**. The website and user guide
are **English**, with matching Italian UI labels. Projects save manually. Custom
libraries are local and should be kept consistent when sharing projects.
